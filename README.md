# Word Styles Microlearning

> Interactive microlearning app for Microsoft Word Styles — 10 levels, animated demos with voice narration, and a gamified quiz loop. By Dr. De Souza · DR.DE.SOUZ.AI
>
> **[▶ Launch the app](https://mrdesouzaphd-cmyk.github.io/word-styles-microlearning/)**
>
> ---
>
> ## What it is
>
> A single-page, browser-based microlearning module teaching Microsoft Word Styles through a three-phase loop:
>
> | Phase | What happens |
> |-------|-------------|
> | **LEARN** | Concept explanation with visual Word UI |
> | **SEE** | Animated screen recording with voice narration |
> | **PROVE** | Before/after quiz with instant feedback |
>
> 10 progressive levels covering heading hierarchies, paragraph styles, style sets, and document consistency.
>
> ## Gamification
>
> - Points awarded on first-try correct answers
> - - Streak bonuses for consecutive correct responses
>   - - Power-ups unlocked at milestones
>    
>     - ## Design rationale
>    
>     - Built to demonstrate that technology training can be **scenario-based, self-paced, and immediately applicable** — not slide decks read aloud. Developed as a proof-of-concept for adult learner upskilling in legal and corporate environments.
>    
>     - ## Stack
>
> Single HTML file · Vanilla JS · CSS animations · Web Speech API · GitHub Pages
